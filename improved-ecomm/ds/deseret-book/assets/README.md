# assets/

`icons/` holds 22 vendored Lucide SVGs (v0.487.0, ISC) — the substituted icon set, mirrored in `components/core/Icon.jsx`. Everything else here is **empty by design**: the uploaded `deseret-book-brand.skill` contained no logo, emblem, monogram, illustration, photography, or icon files — only three reference documents and a tokens CSS file. Nothing was drawn, reconstructed, or generated to fill the gap.

Where a mark belongs, this system sets **"Deseret Book" in Lora Regular, charcoal** (see `guidelines/brand-wordmark.card.html`). When the real art arrives, drop it here as:

- `logo.svg` — full logo (emblem + wordmark), min 200px digital
- `wordmark.svg` — min 150px digital
- `emblem.svg` — min 56px digital; may be scaled far beyond normal size as a watermark
- `monogram.svg` — min 32px digital

Clear space: the height of the "e" in "Deseret" for logo and wordmark. Render marks in a single color — charcoal on light grounds, white on dark.

Icons are a flagged substitution — the brand guide defines no icon set. See ICONOGRAPHY in the root readme.
